My resume

Hi! I'm Nikita, the creator of this website. Originally intended as a purely portfolio site, it evolved into an intriguing journey, leading me to transform it into a fully functional web platform for students and tutors. Initially, I planned for a blog and quiz website, but as development progressed, I expanded it to include a registration and login system, a calendar app, JavaScript crossword puzzle generator and chess.

The platform now has a comprehensive dashboard with basic functionalities like adding, editing, and removing blogs and quizzes. Additionally, I introduced a scheduling feature, allowing teachers to add classes, along with a simple chat application for communication between tutors and students. Ultimately, the platform is designed to facilitate class management, keeping tabs on the number of classes, and more.

Features

Blogging. Users who are tutors can create, edit and delete their blog posts. Blog post creatiion is done on a rich text editor. Users can create a draft and finish it up later before final posting.

Quizzes. A tutor can create quizzes. Created quizzes can be edited by their authors, questions can be added, edited or deleted. Students are later assigned a quiz of quiz can go and be open for everyone.

Chat. Chat with other tutors and students. Chat was implemented using Django signals. Tutors and studdents can chat and appoint their next class.

Calendar. Students can see their sheduled classes in their calendar. Tutors can create, update, delete a class in/from the calendar.

A chess game with a moderately intelligent AI player and a few other games.
