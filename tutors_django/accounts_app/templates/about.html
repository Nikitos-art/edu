Here's my face :-)

Hi! I'm Nikita, the creator of this website, which is my portfolio project as well as a fully functioning web platform for students and tutors. It started with some basic features of Blog, Quiz, and Registration, Login. As development progressed, I added a Scheduler, and a Chat, built with Django Signals. Later I added some JavaScript games: Crossword Puzzle Generator, Chess with single and multiplayer mode and a Chinese characters learning game. You can check it all out in the Games section.

But the most adventerous was setting up the backend. There's a lot of things going on there. Linux and Nginx with Gunicorn handle the backbone. I've also set up a a Linux firewall to keep unwanted traffic from hitting my server. Daily there's over 50+ unwanted hits. And this is with Cloudflare installed to handle a big chunk of the traffic for protection. And finally I decided to share some Python mini-programs, which could be found in Python section.

Features

Blogging. Users who are tutors can create, edit and delete their blog posts. Blog post creatiion is done on a rich text editor. Users can create a draft and finish it up later before final posting. (unfortunately you will need to register and login to create your own blog posts, but you can read mine here ).

Quizzes. A tutor can create quizzes. Created quizzes can be edited by their authors, questions can be added, edited or deleted. Students are later assigned a quiz of quiz can go and be open for everyone. Quiz was built ina similar fashion as blog.

Chat. Chat with other tutors and students. Chat was implemented using Django signals. Tutors and studdents can chat and appoint their next class. You will need to register and log in to see this feature for yourself.

Calendar. Students can see their sheduled classes in their calendar. Tutors can create, update, delete a class in/from the calendar.

A chess game with a moderately intelligent AI player and a multiplayer mode built with Django Channels, so you can invite your friends to play!

Crossword puzzle generator. This one was hard to built and its far from perfect. Current algorithm only allows one "intersection" between words.

I have learned and attempted to learn several foreign langauges. So building something that helps to learn Chinese Mandarin was a must :-)

Some Python tasks suitable for beginners and beginner-mid level Pythonistas.
