I needed to think of an approach as to how actually implement the very core
of the generator. So I decided to create a "chain" of words that would be arranged
on after another (sorting algorithm) if they have a letter in common. For a start
one letter will do. Then see if there's more comon letters. But that's later.
So the "chain" would be created before the placement of words on the grid.
