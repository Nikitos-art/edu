        def ip_to_bin(ip_address):
            ip = ip_address.split("/")[0].split(".")
            result = ""

            for byte in ip:
                byte_elem = bin(int(byte))[2:]
                padding_length = (8 - len(byte_elem) % 8) % 8
                binary_representation = f"{'0' * padding_length + byte_elem} "
                result += binary_representation

            return result
Explanation:
  First I break up the input string by using Python's split method so that I end up with 4 octets of the IP address.
Then I loop over each octet and turn in into binary format using Python's build-in bin() function. I also remove "0b"
prefix that goes along with that. Finally, I needed to add zeros as "padding" (if necessary) to improve readability of
reading binary numbers.
