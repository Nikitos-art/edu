Gear Axis Alignment Varifier Function

Task: Implement a function that checks if gears's axis are in alignment.
Purpose: To develop algorithmic and mathematical thinking.
I first built a function to check if only two gears are in alignment and I used 'distance formula'
to check the distance between two axis' centers. That can be considered the base case. Hooray. Done!
Oh, also, I built a helper function using turtle module to help visualize the axis when adjusting
the inputs for testing and trials.

Next step was to modify the function and make it accept any number of gears' tuples with coordinates and
radii. That was more tricky and I used some AI help for that. So...

Step 1) Define the function and sort x and y coordinates, and radii into
sepaarte lists.

Step 2) Make sure all coordinates are integers and all radii are positive.

Step 3) Use the distance formula ina for loop to check that the distance
between two consequtive gears and their radii are equal.
