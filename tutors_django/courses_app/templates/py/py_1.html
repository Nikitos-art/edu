IPv4 addr converter

Task: Convert an IPv4 address from decimal numbers of each octet into binary number.
Purpose: Improve your understanding of IPv4 addresses along with Python skills
application, which includes: functions, function attributes, for loops, control flow, variables.

The octet is a unit of digital information in computing and telecommunications
that consists of eight bits.

In an IPv4 address the numbers to go above 255, which is the largest decimal number
that can be represented by all 8 bits being 1. Meaning 1111 1111 in binary notation equals 255
in decimal.

So here's one approach:

Step 1) Define the function that takes a string as an input.

Step 2) Check if input is a string and return false if it isn't.

Step 3) Break up the string into parts using Python's split() method,
and use "." as a separator and assign the result (should be a list with 4 elements in it)
to a variable.

Step 4) Use a for loop to iterate over the result of the previous step to check if each
octet is indeed an integer and with in the range of 0 to 255.

Step 5) Last but not least, check the length of the ip_address list (from Step 3) and make
sure its length equals to 4, and if it doesn't return False.
