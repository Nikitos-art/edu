Encrypt / Decrypt (Cipher)

Task: Build a single function that would take a string as input and a true/false value
to encode/decode.

Purpose: Practice Python's Unicode built-in functions.

Unicode is an encoding standard and a true marvel of ingenuity that extended computers' aility
to work with not only Latin alphabet but... all alphabets known to us right now, or at least the
huge portion of them. For more on Unicode follow this link.

Step 1) Define the function and it's attributes. I made use of keyword
argument and assigned a default value to it. Default value when True will be handled as
to encode the text, while setting it to False when calling the function will behandled as
to decode the input.
Step 2) Decide on what manipulations you want to make to actually implement
the cipher. I decided to do it in 2 steps - first, reverse the string, then shift the letter/symbol
to the left or to the right. I used anarbitrary number 2 to do this. So to encode I shift by 2
and to decode I shift back by two. I used Python's built-in function ord() to get the decimal
representation of a text symbol to perform the shift.
Step 3) Convert the list with decimals from the previous step back into their
corresponding representation in text.
Hint: I first buildtwo separate function for thistask and then refactored the
code to combine them into one function.
