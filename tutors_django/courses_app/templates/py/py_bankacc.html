Custom Bank Account Class

Task: Make a custom class that would represent a bank account with all the required
functionality of a bank account - deposit, withdraw, transfer, and show balance.
Purpose: To practice Python fundamentals for OOP.

Step 1) Create a class attribute accounts to store all accounts. Define
the __init__ constructor method with attributes _balance (private) and acc_num (unique account
number). Add a check to ensure balance is non-negative and acc_num is unique..

Step 2) Implement deposit to increase _balance by a specified amount. Add
validation to ensure the deposit amount is non-negative.

Step 3) Implement withdraw method to decrease _balance by a specified amount.
Validate that the withdrawal amount is non-negative and doesn't exceed the available balance.

Step 4) Add Transfer Method: validate sufficient funds before transferring.
Use the deposit method of the beneficiary account.

Step 5) Implement Balance Access: Use a @property for read-only access to _balance.

Step 6) Implement String Representation: define __repr__ for a clean and informative
string representation of the account.

Optional: try to implement a password protection or account holder info, or expand functionality with
get_transaction history method.
