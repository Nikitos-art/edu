Custom Dict Class

Task: Implement a custom dictionary class with basic functionality of Python's dictionaries.
Purpose: To practice OOP by creating a custom class, mimicking Python's built-in dictionary.
This exercise deepens understanding of Python classes, data structure design, and fundamental
programming concepts.

Step 1) Define the class and add an __init__ method to initialize the hash
table and its size. The hash table will be represented as a list of empty lists (buckets), one
for each hash index.

Step 2) Create a hash function, define a private method _hash to compute
the index for a given key.

Step 3) Define a method set(self, key, value) to add or update key-value
pairs. Hash the key to find its index. Search the bucket at the computed index for the key.
If the key exists, update its value. If not, append a new key-value pair to the bucket.

Step 4) Add the get Method. Define a method get(self, key) to retrieve
the value for a given key. Hash the key to locate the appropriate bucket. Search for the key
in the bucket and return its value if found. Raise a KeyError if the key is not in the bucket.

Step 5) Add the delete Method. Define a method delete(self, key) to remove
a key-value pair. Hash the key to locate the bucket. Search for the key in the bucket, remove
the pair if found, and stop. Raise a KeyError if the key does not exist.

Step 6) Add a string representation.
