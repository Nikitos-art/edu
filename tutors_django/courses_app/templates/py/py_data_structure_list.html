Custom List Class

Task: Build a custom list class. The class must have at least append, get, find, and
len methods.
Purpose: To practice Object-Oriented Programming (OOP) principles by designing and
implementing a custom class. This exercise aims to provide a deeper understanding of how Python's
classes work, how data structures are built and manipulated, and how to mimic the behavior of
Python's built-in list to solidify programming fundamentals.
You can get a look at the methods and attriburtes of a built-in class by print(dir(list))
or by help(list).

Step 1) First, define the class using the class keyword.

Step 2) Initialize storage: inside the__init__ method define an internal list
to hold the elements.

Step 3) Implement the append method to add elements to the end of the list.

Step 4) Implement the append method to retrieve an element by its
index, with basic error handling.

Step 5) Implement the find method to search for a value and return
its index. Return -1 if not found.

Step 5) Implement the __len__ to return the number of elements.

Step 6) Add a string representation (__repr__).
